## Original Problem

You are given a string s that consists of lower case English letters and brackets.

Reverse the strings in each pair of matching parentheses, starting from the innermost one.

Your result should not contain any brackets.

Example 1:

Input: s = "(abcd)"
Output: "dcba"

Example 2:

Input: s = "(u(love)i)"
Output: "iloveu"
Explanation: The substring "love" is reversed first, then the whole string is reversed.

Example 3:

Input: s = "(ed(et(oc))el)"
Output: "leetcode"
Explanation: First, we reverse the substring "oc", then "etco", and finally, the whole string.

Constraints:

- 1 <= s.length <= 2000

- s only contains lower case English characters and parentheses.

- It is guaranteed that all parentheses are balanced.

**Examples / sample tests:**

```
"(abcd)"
"(u(love)i)"
"(ed(et(oc))el)"
```

## Problem Summary
Given a string containing lowercase English letters and balanced parentheses, the task is to reverse the substrings enclosed within each pair of matching parentheses. This reversal must happen from the innermost parentheses outwards. The final result should be a string containing only letters, with no brackets.

## Intuition
The problem's requirement to reverse "starting from the innermost one" is a strong hint for using a **stack** data structure. A stack is perfect for handling nested structures because it follows a Last-In, First-Out (LIFO) principle, naturally processing the most recently opened (and thus innermost) context first when a closing event occurs.

When we encounter an opening parenthesis `(`, it signifies that we are entering a new, deeper level of nesting. We need to "save" the string content we've built so far at the current level and start building a new string for this inner level.
When we encounter a closing parenthesis `)`, it means the current inner string segment is complete. We should reverse it and then merge it back into the string content of the immediately outer level, which we previously "saved".

## Approach
We will use a **stack** to manage the nesting levels and a list of characters (`result_parts`) to efficiently build and manipulate the current string segment.

1.  **Initialization**:
    *   Create an empty list `result_parts`. This list will accumulate characters for the current string segment being built. Using a list of characters is more efficient for appending and reversing than repeatedly concatenating strings in Python.
    *   Create an empty list `stack`. This stack will store `result_parts` lists when we encounter an opening parenthesis, effectively saving the "outer" string context.

2.  **Iterate through the string `s`**:
    *   For each `char` in `s`:
        *   **If `char` is `(` (opening parenthesis):**
            *   This marks the beginning of a new, inner segment.
            *   **Push** the current `result_parts` list onto the `stack`. This saves the characters accumulated for the *outer* segment.
            *   **Reset** `result_parts` to an empty list `[]`. We now start accumulating characters for this *new inner* segment.
        *   **If `char` is `)` (closing parenthesis):**
            *   This marks the end of the current inner segment. The `result_parts` list currently holds the characters of this segment.
            *   **Reverse** the `result_parts` list in-place.
            *   **Pop** a list from the `stack`. This `prev_parts` list represents the characters of the *outer* segment that was saved when the matching `(` was encountered.
            *   **Extend** `prev_parts` with the now-reversed `result_parts`. This merges the reversed inner segment back into its outer context.
            *   **Update** `result_parts` to be `prev_parts`. The combined list now becomes the active `result_parts` for the ongoing (outer) segment.
        *   **If `char` is a letter:**
            *   **Append** `char` to the current `result_parts` list.

3.  **Final Result**:
    *   After iterating through the entire input string, `result_parts` will contain all characters in their final, correct order.
    *   **Join** the characters in `result_parts` to form the final string and return it.
