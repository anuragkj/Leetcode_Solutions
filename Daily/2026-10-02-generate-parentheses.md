## Original Problem

Given n pairs of parentheses, write a function to generate all combinations of well-formed parentheses.

Example 1:

Input: n = 3
Output: ["((()))","(()())","(())()","()(())","()()()"]

Example 2:

Input: n = 1
Output: ["()"]

Constraints:

- 1 <= n <= 8

**Examples / sample tests:**

```
3
1
```

## Problem Summary
The problem asks us to generate all possible combinations of `n` pairs of parentheses such that each combination forms a "well-formed" sequence. A well-formed sequence means that parentheses are correctly matched and nested (e.g., "()()" and "(())" are well-formed, but "())(" is not).

## Intuition
To generate all well-formed parenthesis sequences, we need a systematic way to build them character by character. The key insight lies in the rules for a sequence to be well-formed:
1.  The total number of opening parentheses must equal the total number of closing parentheses (`n` of each).
2.  At any point while reading the sequence from left to right, the number of opening parentheses encountered so far must be greater than or equal to the number of closing parentheses encountered so far. You can never close a parenthesis if there isn't an open one to match it.

This naturally leads to a **recursive** or **backtracking** approach. We can build the string by deciding whether to add an opening `(` or a closing `)` at each step. We need to keep track of how many open and close parentheses we've used so far to ensure we follow the rules.

## Approach
We will use a **backtracking** algorithm to explore all valid combinations.

1.  **Initialize**: Create an empty list, `result`, to store all well-formed parenthesis strings.
2.  **Define a Backtracking Function**: Create a recursive helper function, let's call it `backtrack(current_string, open_count, close_count)`.
    *   `current_string`: The parenthesis sequence built so far.
    *   `open_count`: The number of opening parentheses `(` already placed in `current_string`.
    *   `close_count`: The number of closing parentheses `)` already placed in `current_string`.
3.  **Base Case**:
    *   If `open_count == n` AND `close_count == n`, it means we have successfully placed all `n` pairs of parentheses, and the `current_string` is well-formed. Add `current_string` to our `result` list and return.
4.  **Recursive Steps (Choices)**:
    *   **Option 1: Add an opening parenthesis `(`**:
        *   We can add an opening parenthesis if `open_count < n` (i.e., we haven't used all `n` opening parentheses yet).
        *   If this condition is met, recursively call `backtrack(current_string + "(", open_count + 1, close_count)`.
    *   **Option 2: Add a closing parenthesis `)`**:
        *   We can add a closing parenthesis only if `close_count < open_count`. This is the crucial rule that ensures well-formedness: you can only close a parenthesis if there's an unmatched open one before it.
        *   If this condition is met, recursively call `backtrack(current_string + ")", open_count, close_count + 1)`.
5.  **Initial Call**: Start the backtracking process by calling `backtrack("", 0, 0)` from the main function.
6.  **Return**: After the initial call completes, return the `result` list.

## Complexity
*   **Time Complexity**: `O(C_n * 2n)`, where `C_n` is the `n`-th Catalan number.
    *   The number of well-formed parenthesis sequences of `n` pairs is given by the `n`-th Catalan number, `C_n = 1/(n+1) * (2n choose n)`.
    *   For each of these `C_n` sequences, we build a string of length `2n`. String concatenation in Python creates new strings, taking `O(length)` time.
    *   `C_n` grows exponentially, approximately `4^n / (n^(3/2) * sqrt(pi))`. So, the time complexity is roughly `O(4^n / sqrt(n))`.
*   **Space Complexity**: `O(C_n * 2n)` for the result list, plus `O(2n)` for the recursion stack depth.
    *   The `result` list stores `C_n` strings, each of length `2n`.
    *   The maximum depth of the recursion stack is `2n` (the length of the longest possible parenthesis sequence).

## Edge Cases
*   **`n = 1`**: The solution correctly generates `["()"]`. The backtracking starts with `("", 0, 0)`. It adds `(` to become `("(", 1, 0)`. Then it can only add `)` to become `("()", 1, 1)`. At this point, `open_count == n` and `close_count == n`, so `()` is added to the result.
*   **`n = 8` (maximum constraint)**: The algorithm will generate all `C_8 = 1430` unique well-formed parenthesis sequences, each of length `16`. The exponential nature of Catalan numbers means this is the practical limit for `n` in competitive programming contexts. The solution handles this by simply generating all valid combinations within the given constraints.

## Solution

```python
class Solution:
    def generateParenthesis(self, n: int) -> list[str]:
        result = [] # This list will store all valid parenthesis combinations

        # The backtracking function
        # current_string: The string built so far
        # open_count: Number of '(' characters used
        # close_count: Number of ')' characters used
        def backtrack(current_string, open_count, close_count):
            # Base case: If we have used all 'n' open and 'n' close parentheses,
            # we have a complete and well-formed sequence.
            if open_count == n and close_count == n:
                result.append(current_string)
                return

            # Recursive step 1: Try adding an opening parenthesis '('
            # We can add an opening parenthesis if we haven't used all 'n' of them yet.
            if open_count < n:
                backtrack(current_string + "(", open_count + 1, close_count)

            # Recursive step 2: Try adding a closing parenthesis ')'
            # We can add a closing parenthesis only if it maintains well-formedness.
            # This means the number of closing parentheses must be less than the number of open ones.
            # (i.e., there's an open parenthesis available to be closed).
            if close_count < open_count:
                backtrack(current_string + ")", open_count, close_count + 1)

        # Start the backtracking process with an empty string and zero counts
        backtrack("", 0, 0)
        return result

```

## Why This Works
This backtracking approach works because it systematically explores all possible sequences of parentheses while strictly adhering to the two rules for well-formedness at every step. The condition `open_count < n` ensures we never exceed the total allowed opening parentheses. The condition `close_count < open_count` is critical: it guarantees that we only place a closing parenthesis if there's an unmatched opening one preceding it, preventing sequences like `)(` or `())`. By exploring all valid additions of `(` and `)` until both counts reach `n`, we guarantee that all combinations generated are well-formed and that no valid combination is missed.
