## Original Problem

Alice and Bob take turns playing a game, with Alice starting first.

You are given a string num of even length consisting of digits and '?' characters. On each turn, a player will do the following if there is still at least one '?' in num:

- Choose an index i where num[i] == '?'.

- Replace num[i] with any digit between '0' and '9'.

The game ends when there are no more '?' characters in num.

For Bob to win, the sum of the digits in the first half of num must be equal to the sum of the digits in the second half. For Alice to win, the sums must not be equal.

- For example, if the game ended with num = "243801", then Bob wins because 2+4+3 = 8+0+1. If the game ended with num = "243803", then Alice wins because 2+4+3 != 8+0+3.

Assuming Alice and Bob play optimally, return true if Alice will win and false if Bob will win.

Example 1:

Input: num = "5023"
Output: false
Explanation: There are no moves to be made.
The sum of the first half is equal to the sum of the second half: 5 + 0 = 2 + 3.

Example 2:

Input: num = "25??"
Output: true
Explanation: Alice can replace one of the '?'s with '9' and it will be impossible for Bob to make the sums equal.

Example 3:

Input: num = "?3295???"
Output: false
Explanation: It can be proven that Bob will always win. One possible outcome is:
- Alice replaces the first '?' with '9'. num = "93295???".
- Bob replaces one of the '?' in the right half with '9'. num = "932959??".
- Alice replaces one of the '?' in the right half with '2'. num = "9329592?".
- Bob replaces the last '?' in the right half with '7'. num = "93295927".
Bob wins because 9 + 3 + 2 + 9 = 5 + 9 + 2 + 7.

Constraints:

- 2 <= num.length <= 10^5

- num.length is even.

- num consists of only digits and '?'.

## Problem Summary
Alice and Bob fill '?' characters in a given even-length string `num` with digits '0'-'9'. Alice starts. Alice wants the sum of digits in the first half to be different from the second half. Bob wants them to be equal. We need to determine if Alice wins assuming optimal play.

## Intuition
This is a **game theory** problem. Both players play optimally. Alice wants to maximize the absolute difference between the sums of the two halves, while Bob wants to minimize it (ideally to zero).

Let's denote:
*   `s_left`: sum of known digits in the first half.
*   `s_right`: sum of known digits in the second half.
*   `q_left`: count of '?' in the first half.
*   `q_right`: count of '?' in the second half.

The game ends when all `q_left + q_right` question marks are filled.
Alice makes `N_A = ceil((q_left + q_right) / 2)` moves.
Bob makes `N_B = floor((q_left + q_right) / 2)` moves.

Consider the **difference in sums**: `D = (final_sum_left) - (final_sum_right)`.
Alice wants `D != 0`. Bob wants `D == 0`.

What is the optimal strategy for each player when filling a '?'?
*   **Alice's goal**: Maximize `abs(D)`.
    *   If she fills a '?' in the **left half**, she wants to increase `final_sum_left`. She'll place '9'. This increases `D` by 9.
    *   If she fills a '?' in the **right half**, she wants to decrease `final_sum_right`. She'll place '0'. This increases `D` by 0.
    *   Alice will always choose to fill a left '?' with '9' if available, as it gives a +9 advantage to `D`. If no left '?'s are available, she'll fill a right '?' with '0'.
*   **Bob's goal**: Minimize `abs(D)`.
    *   If he fills a '?' in the **left half**, he wants to decrease `final_sum_left`. He'll place '0'. This increases `D` by 0.
    *   If he fills a '?' in the **right half**, he wants to increase `final_sum_right`. He'll place '9'. This decreases `D` by 9.
    *   Bob will always choose to fill a right '?' with '9' if available, as it gives a -9 advantage to `D`. If no right '?'s are available, he'll fill a left '?' with '0'.

This greedy strategy for both players determines the final `D`.
