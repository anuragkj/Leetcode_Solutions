## Original Problem

Given an array of integers arr, return the number of subarrays with an odd sum.

Since the answer can be very large, return it modulo 10^9 + 7.

Example 1:

Input: arr = [1,3,5]
Output: 4
Explanation: All subarrays are [[1],[1,3],[1,3,5],[3],[3,5],[5]]
All sub-arrays sum are [1,4,9,3,8,5].
Odd sums are [1,9,3,5] so the answer is 4.

Example 2:

Input: arr = [2,4,6]
Output: 0
Explanation: All subarrays are [[2],[2,4],[2,4,6],[4],[4,6],[6]]
All sub-arrays sum are [2,6,12,4,10,6].
All sub-arrays have even sum and the answer is 0.

Example 3:

Input: arr = [1,2,3,4,5,6,7]
Output: 16

Constraints:

- 1 <= arr.length <= 10^5

- 1 <= arr[i] <= 100

**Examples / sample tests:**

```

[2,4,6]

## Problem Summary
Given an array of integers, we need to count how many of its contiguous subarrays have an odd sum. Since the total count can be very large, the result should be returned modulo 10^9 + 7.

## Intuition
Let's think about the sum of a subarray `arr[i...j]`. This sum can be expressed using **prefix sums**. If `P[k]` is the sum of `arr[0...k]`, then `arr[i...j]` is `P[j] - P[i-1]`. (We define `P[-1] = 0` for convenience, so `arr[0...j]` is `P[j] - P[-1]`).

We are interested in subarrays where `P[j] - P[i-1]` is **odd**.
Recall the rules for parity in subtraction:
- `Odd - Even = Odd`
- `Even - Odd = Odd`
- `Odd - Odd = Even`
- `Even - Even = Even`

This means that for `P[j] - P[i-1]` to be odd, `P[j]` and `P[i-1]` must have **different parities**.

So, as we iterate through the array and calculate `P[j]` (our `current_prefix_sum`), we need to count how many *previous* prefix sums `P[i-1]` have the **opposite parity** of `P[j]`.

## Approach
We can solve this efficiently by keeping track of the counts of even and odd prefix sums encountered so far.

1.  Initialize `total_odd_subarrays = 0`. This will store our final answer.
2.  Initialize `current_prefix_sum = 0`. This will accumulate the sum of elements as we iterate.
3.  Initialize `count_even_prefix_sums = 1`. This is crucial: it accounts for the "empty" prefix sum (which is 0, an even number) before we start processing the array. This handles subarrays that start from index 0.
4.  Initialize `count_odd_prefix_sums = 0`.
5.  Define `MOD = 10**9 + 7` for modulo operations.
6.  Iterate through each `num` in the input array `arr`:
    a.  Add `num` to `current_prefix_sum`.
    b.  Check the parity of `current_prefix_sum`:
        *   If `current_prefix_sum` is **odd**:
            *   To form an odd-sum subarray ending at the current position, we need a previous prefix sum that is **even**.
            *   Add `count_even_prefix_sums` to `total_odd_subarrays`.
            *   Increment `count_odd_prefix_sums` (because the `current_prefix_sum` is odd).
        *   If `current_prefix_sum` is **even**:
            *   To form an odd-sum subarray ending at the current position, we need a previous prefix sum that is **odd**.
            *   Add `count_odd_prefix_sums` to `total_odd_subarrays`.
            *   Increment `count_even_prefix_sums` (because the `current_prefix_sum` is even).
    c.  Apply the modulo `MOD` to `total_odd_subarrays` after each addition to prevent overflow.
7.  After iterating through all elements, return `total_odd_subarrays`.

class Solution:
    def numOfSubarrays(self, arr: list[int]) -> int:
        MOD = 10**9 + 7
        
        # current_prefix_sum stores the sum of elements from arr[0] up to the current element.
        # We only care about its parity, so we can store current_prefix_sum % 2.
        # However, keeping the actual sum helps understand the logic better,
        # and its value doesn't grow large enough to overflow Python's integers.
        current_prefix_sum = 0
        
        # count_even_prefix_sums stores how many prefix sums encountered so far have been even.
        # Initialize to 1 to account for the "empty" prefix sum (0) before the array starts.
        # This handles subarrays that start from index 0. For example, if arr[0] is odd,
        # then current_prefix_sum becomes odd. We need to pair it with an even previous prefix sum.
        # The "empty" prefix sum 0 is even, so it contributes 1 to count_even_prefix_sums,
        # correctly counting arr[0] as an odd-sum subarray.
        count_even_prefix_sums = 1 
        
        # count_odd_prefix_sums stores how many prefix sums encountered so far have been odd.
        # Initially, no odd prefix sums have been encountered.
        count_odd_prefix_sums = 0
        
        # total_odd_subarrays will store our final answer.
        total_odd_subarrays = 0
        
        # Iterate through each number in the input array.
        for num in arr:
            # Update the current prefix sum.
            current_prefix_sum += num
            
            # The core logic:
            # A subarray sum arr[i...j] is P[j] - P[i-1].
            # This difference is ODD if and only if P[j] and P[i-1] have DIFFERENT parities.
            # P[j] is our current_prefix_sum.
            # P[i-1] are the previous prefix sums whose counts we maintain.
            
            if current_prefix_sum % 2 == 1: # If current_prefix_sum is ODD
                # To make (ODD - previous_prefix_sum) result in ODD,
                # previous_prefix_sum must be EVEN.
                # So, we add the count of all previously encountered EVEN prefix sums
                # to our total. Each of these forms a new odd-sum subarray ending here.
                total_odd_subarrays = (total_odd_subarrays + count_even_prefix_sums) % MOD
                
                # Since current_prefix_sum is odd, we increment the count of odd prefix sums.
                count_odd_prefix_sums += 1
            else: # If current_prefix_sum is EVEN
                # To make (EVEN - previous_prefix_sum) result in ODD,
                # previous_prefix_sum must be ODD.
                # So, we add the count of all previously encountered ODD prefix sums
                # to our total. Each of these forms a new odd-sum subarray ending here.
                total_odd_subarrays = (total_odd_subarrays + count_odd_prefix_sums) % MOD
                
                # Since current_prefix_sum is even, we increment the count of even prefix sums.
                count_even_prefix_sums += 1
                
        return total_odd_subarrays

```

## Why This Works

The solution leverages the properties of prefix sums and parity. A subarray sum `arr[i...j]` can be expressed as `P[j] - P[i-1]`, where `P[k]` is the sum of elements from `arr[0]` to `arr[k]`. For this difference to be odd, `P[j]` and `P[i-1]` must have different parities (one odd, one even).

As we iterate through the array and compute `P[j]` (our `current_prefix_sum`), we effectively ask: "How many previous prefix sums `P[i-1]` (where `i-1 < j`) have the opposite parity of `P[j]`?" Each such `P[i-1]` forms an odd-sum subarray `arr[i...j]` with the current `P[j]`. By maintaining `count_even_prefix_sums` and `count_odd_prefix_sums`, we efficiently count these pairs. The initialization `count_even_prefix_sums = 1` correctly handles subarrays starting from index 0, as `P[-1]` is conceptually 0 (even), allowing `P[j] - P[-1]` to be odd if `P[j]` is odd. This ensures every valid odd-sum subarray is counted exactly once.
