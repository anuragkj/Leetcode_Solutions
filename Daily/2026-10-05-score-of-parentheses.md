## Original Problem

Given a balanced parentheses string s, return the score of the string.

The score of a balanced parentheses string is based on the following rule:

- "()" has score 1.

- AB has score A + B, where A and B are balanced parentheses strings.

- (A) has score 2 * A, where A is a balanced parentheses string.

Example 1:

Input: s = "()"
Output: 1

Example 2:

Input: s = "(())"
Output: 2

Example 3:

Input: s = "()()"
Output: 2

Constraints:

- 2 <= s.length <= 50

- s consists of only '(' and ')'.

- s is a balanced parentheses string.

**Examples / sample tests:**

```
"()"
"(())"
"()()"
```

## Problem Summary
Given a balanced parentheses string, calculate its score. The score is defined recursively: "()" scores 1; "AB" scores A + B; and "(A)" scores 2 * A, where A and B are balanced parentheses strings.

## Intuition
The problem involves nested structures and recursive scoring rules (summing for `AB`, multiplying for `(A)`). This is a classic indicator for a **stack-based approach**. We can process the string character by character, using the stack to keep track of the scores accumulated at different nesting levels.

When we encounter an opening parenthesis `(`, we are entering a new, deeper level. We should push a placeholder (like `0`) onto the stack to represent the score for this new level.

When we encounter a closing parenthesis `)`, we are completing a level. We need to:
1.  Pop the score accumulated *within* this just-closed level.
2.  Determine if this segment was a simple `()` (score 1) or a `(A)` (score `2 * A`).
3.  Add this calculated score to the score of the *parent* level, which will be at the top of the stack.

By initializing the stack with `[0]` (representing the total score of the outermost level), we ensure there's always a parent level to add to.

## Approach
1.  Initialize a **stack** with a single element: `[0]`. This `0` will accumulate the total score for the entire string.
2.  Iterate through each `char` in the input string `s`:
    *   If `char` is `(`:
        *   Push `0` onto the stack. This `0` acts as a placeholder for the score of the newly opened, deeper level.
    *   If `char` is `)`:
        *   **Pop** the `current_level_score` from the stack. This is the score that was accumulated inside the just-closed parentheses.
        *   Calculate the `segment_score` for the just-closed part:
            *   If `current_level_score == 0`, it means we just closed a simple `()` pair. Its score is `1`.
            *   If `current_level_score > 0`, it means we just closed a `(A)` pair, where `A` had a score of `current_level_score`. Its score is `2 * current_level_score`.
        *   Add this `segment_score` to the **parent level's score**, which is currently at the top of the stack (`stack[-1]`).
3.  After iterating through the entire string, the final total score will be the only element remaining in the stack: `stack[0]`. Return this value.

                                                                                                                                                                                                                                                                                Score of Parentheses
## Problem Summary
Given a balanced parentheses string, calculate its score based on specific rules: "()" has a score of 1; "AB" scores A + B; and "(A)" scores 2 * A.

## Intuition
The problem defines a recursive structure for calculating scores, which often suggests using a **stack** to manage nested computations. Each time we encounter an opening parenthesis `(`, it signifies the start of a new, deeper level of calculation. When we encounter a closing parenthesis `)`, it means we've completed a segment and need to finalize its score and contribute it to the score of the *parent* level.

The key idea is that the stack will store the **cumulative score for each open parenthesis level**.
- When we see `(`, we push a `0` onto the stack. This `0` represents the score for the new, deeper level, which starts empty.
- When we see `)`, we pop the score from the top of the stack. This is the `current_level_score` (the score of `A` if the segment was `(A)`).
    - If `current_level_score` is `0`, it means the segment was `()`, so its score is `1`.
    - If `current_level_score` is greater than `0`, it means the segment was `(A)`, so its score is `2 * current_level_score`.
- This calculated score is then added to the score of the *parent* level, which is now at the top of the stack (`stack[-1]`).

By initializing the stack with `[0]`, we ensure there's always a base level to accumulate the final total score.

## Approach
1.  Initialize an empty list called `stack` and push `0` onto it. This `0` will serve as the accumulator for the total score of the outermost level.
2.  Iterate through each `char` in the input string `s`:
    *   If `char` is an opening parenthesis `(`:
        *   Push `0` onto the `stack`. This `0` represents the score for the new, deeper level that has just begun.
    *   If `char` is a closing parenthesis `)`:
        *   **Pop** the `current_level_score` from the `stack`. This value is the score accumulated within the parentheses that are now closing.
        *   Determine the `segment_score` based on the rules:
            *   If `current_level_score` is `0`, it implies the segment was a simple `()`. According to the rules, its score is `1`.
            *   If `current_level_score` is greater than `0`, it implies the segment was `(A)`, where `A` had a score of `current_level_score`. According to the rules, its score is `2 * current_level_score`.
        *   Add this `segment_score` to the value at the top of the `stack` (`stack[-1]`). This effectively adds the score of the just-closed segment to its parent's score.
3.  After the loop finishes processing all characters in `s`, the `stack` will contain only one element, which is the total score of the entire string. Return `stack[0]`.

                                                                     Score of Parentheses
## Problem Summary
Given a balanced parentheses string, calculate its score based on three rules: "()" scores 1; "AB" (concatenation) scores A + B; and "(A)" (nesting) scores 2 * A.

## Intuition
The problem describes a recursive structure for calculating scores, which is a strong hint for using a **stack**. We need a way to keep track of scores at different nesting levels.

Imagine processing the string from left to right:
- When we see an opening parenthesis `(`, we are starting a new, deeper level of calculation. We don't know its score yet, so we can push a placeholder (like `0`) onto our stack to represent the score for this new level.
- When we see a closing parenthesis `)`, it means we've completed a segment of parentheses. We need to:
    1.  **Pop** the score that was accumulated *inside* this just-closed segment. Let's call this `current_level_score`.
    2.  Determine the actual score for this segment:
        *   If `current_level_score` was `0`, it means the segment was a simple `()`. According to the rules, its score is `1`.
        *   If `current_level_score` was greater than `0`, it means the segment was `(A)`, where `A` itself had a score of `current_level_score`. According to the rules, its score is `2 * current_level_score`.
    3.  This calculated score for the segment must then be added to the score of the **parent level**. The parent level's score will be the element now at the top of our stack (`stack[-1]`).

By initializing the stack with `[0]`, we ensure there's always a base level to accumulate the final total score for the entire string.

## Approach
1.  Initialize a list called `stack` with a single element: `[0]`. This `0` will serve as the accumulator for the total score of the outermost level of the entire input string.
2.  Iterate through each `char` in the input string `s` from left to right:
    *   If `char` is an opening parenthesis `(`:
        *   Push `0` onto the `stack`. This `0` acts as a temporary placeholder for the score of the newly opened, deeper level. It will accumulate scores from its children.
    *   If `char` is a closing parenthesis `)`:
        *   **Pop** the `current_level_score` from the `stack`. This value represents the score that was accumulated *within* the parentheses that are now closing.
        *   Calculate the `segment_score` for the just-closed part based on the problem's rules:
            *   If `current_level_score` is `0`, it means the segment was a simple `()`. According to the rule, its score is `1`.
            *   If `current_level_score` is greater than `0`, it means the segment was `(A)`, where `A` itself had a score of `current_level_score`. According to the rule, its score is `2 * current_level_score`.
        *   Add this `segment_score` to the value at the top of the `stack` (`stack[-1]`). This effectively adds the score of the just-closed segment to its parent's score.
3.  After the loop finishes processing all characters in `s`, the `stack` will contain only one element. This element is the total score of the entire string. Return `stack[0]`.
