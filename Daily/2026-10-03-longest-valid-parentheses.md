## Original Problem

Given a string containing just the characters '(' and ')', return the length of the longest valid (well-formed) parentheses substring.

Example 1:

Input: s = "(()"
Output: 2
Explanation: The longest valid parentheses substring is "()".

Example 2:

Input: s = ")()())"
Output: 4
Explanation: The longest valid parentheses substring is "()()".

Example 3:

Input: s = ""
Output: 0

Constraints:

- 0 <= s.length <= 3 * 10^4

- s[i] is '(', or ')'.

## Problem Summary
Given a string consisting only of '(' and ')', the goal is to find the length of the longest substring that forms a well-formed (valid) parentheses sequence.

## Intuition
The problem of checking valid parentheses often involves a **stack**. We can adapt this idea to find the *longest* valid sequence.
Imagine iterating through the string:
1.  When we see an **opening parenthesis `(`**, we want to remember its position, so we push its index onto a stack.
2.  When we see a **closing parenthesis `)`**:
    *   If the stack is not empty, it means we have a matching `(` available. We **pop** the index of that `(`. The length of this newly formed valid pair (or extension of a valid sequence) can be calculated using the current index `i` and the index of the element *below* the popped `(` on the stack.
    *   If the stack *is* empty, it means this `)` has no matching `(` to its left. This `)` effectively breaks any potential valid sequence starting before it. We can then push the current index `i` onto the stack to act as a **new "base" or "boundary"** for calculating future valid lengths.

To handle the calculation of lengths correctly, especially when a valid sequence starts at index 0, we can initialize the stack with a **sentinel value**, typically `-1`. This `-1` represents a "boundary" before the string begins. When we find a valid pair, the length will be `current_index - stack.top()`. If `stack.top()` is `-1`, it correctly calculates the length from index 0.

## Approach
The optimal approach uses a single pass with a stack:

1.  Initialize `max_len = 0` to store the maximum length found so far.
2.  Initialize an empty `stack` and push a **sentinel value `-1`** onto it. This sentinel acts as a base index for calculating lengths of valid parentheses sequences that start from the beginning of the string or after an unmatched `)`.
3.  Iterate through the input string `s` from left to right, using an index `i` for each character `s[i]`:
    a.  If `s[i]` is an **opening parenthesis `(`**:
        *   Push its current index `i` onto the `stack`.
    b.  If `s[i]` is a **closing parenthesis `)`**:
        *   **Pop** the top element from the `stack`.
        *   **Check if the `stack` is now empty**:
            *   If it is empty, it means the `)` we just processed did not find a matching `(` within the current valid segment. This `)` effectively acts as a new "boundary" for future valid sequences. Push the current index `i` onto the `stack` to serve as this new base.
            *   If it is **not empty**, it means we have successfully matched a `)` with an `(`. The length of the current valid parentheses sequence is `i - stack.top()`. Update `max_len = max(max_len, i - stack.top())`.
4.  After iterating through the entire string, return `max_len`.

## Complexity
*   **Time Complexity**: O(N), where N is the length of the string `s`. We iterate through the string once, and each stack operation (push, pop, top) takes O(1) time.
*   **Space Complexity**: O(N), where N is the length of the string `s`. In the worst case (e.g., `(((((`), the stack can store up to N indices.

## Edge Cases
*   **Empty string `""`**: The loop won't run. `max_len` remains `0`, which is correct.
*   **String with only opening parentheses `(((`**: The stack will grow, but `max_len` will remain `0` as no `)` is encountered to form a valid pair. Correct.
*   **String with only closing parentheses `)))`**: The stack will repeatedly become empty and push the current index. `max_len` will remain `0`. Correct.
*   **String with mixed but invalid parentheses `())(()`**: The logic correctly handles unmatched `)` by pushing their indices as new bases, ensuring `max_len` is updated only for valid segments.
*   **String with all valid parentheses `()()()`**: `max_len` will be updated correctly to the full length of the string.

## Solution

```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        max_len = 0
        # Initialize stack with a sentinel value -1.
        # This sentinel helps in calculating lengths correctly,
        # especially for valid sequences starting from index 0.
        # It represents a "boundary" before the first character.
        stack = [-1] 

        for i in range(len(s)):
            if s[i] == '(':
                # If an opening parenthesis, push its index onto the stack.
                stack.append(i)
            else:  # s[i] == ')'
                # If a closing parenthesis, pop the top element.
                stack.pop() 
                
                if not stack:
                    # If the stack becomes empty after popping, it means the current ')'
                    # did not find a matching '(' to its left within the current valid segment.
                    # This ')' effectively acts as a new "boundary" for future calculations.
                    # Push its index onto the stack to serve as this new base.
                    stack.append(i)
                else:
                    # If the stack is not empty, a valid pair has been found.
                    # The length of this valid sequence is the current index 'i'
                    # minus the index of the element at the top of the stack.
                    # The element at stack.top() is either the index of the last unmatched
                    # opening parenthesis or a previous boundary index (like -1 or an unmatched ')').
                    max_len = max(max_len, i - stack[-1])
        
        return max_len

```

## Why This Works
This approach works because the stack consistently maintains the indices of **potential starting points** for valid parentheses sequences. Specifically, the stack always holds indices of unmatched opening parentheses, or the index of the most recent unmatched closing parenthesis (which acts as a new "base" or "left boundary"). When a closing parenthesis `)` is encountered and matches an opening parenthesis `(` (by popping from a non-empty stack), the length of the valid sequence is calculated from the current index `i` back to the index *immediately preceding* the matched `(`. This "preceding index" is precisely `stack.top()`. By always keeping track of this left boundary, whether it's an unmatched `(` or a sentinel/unmatched `)`, we can correctly measure the length of every valid segment and update `max_len` accordingly.
